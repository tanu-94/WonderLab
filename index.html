What's in a Name?

Learn how a simple rule can turn an ordinary message into a secret message.

1. 🌟 What is the Caesar Cipher?

It is a simple way to hide a message.

We move every letter by the same number of places in the alphabet.

ABCDE
⬇️ Shift +2 ⬇️
CDEFG

The number of places we move is called the key.

2. 💡 What does it mean?

🔐 Encrypt = hide

Change the message using the rule.

CODE → EQFG
🔓 Decrypt = reveal

Use the key to bring the message back.

EQFG → CODE
🔑 Key = 2

Every letter moves 2 places forward when we hide the message.

C → EO → QD → FE → G

3. 🕵️ Why do we use this idea?

Sometimes information should not be understood by everyone.

🔑PasswordKeep private
💳Payment informationKeep safe
📱Private messageKeep private
Important: The Caesar Cipher is a classroom model. Modern computers use much stronger security methods to protect real information.

4. 🌍 Where is the idea used?

The idea of protecting information is used when people use passwords, make payments, shop online, or send private information.

🔑Password
💳Online payment
🛒Online shopping
📱Private communication

Remember: Caesar Cipher itself is not the security system used for today's banking or UPI. It is a simple model for learning how a rule can hide information.

5. 👥 Who can use it?

Anyone who knows the rule can use it. One person hides the message. The other person uses the same key to reveal it.

🧒
SENDERMessage + keyCODE↓ Shift +2

6. 🧩 What can we use it for?

🔐 Hide a message

Make a simple secret code.

🧠 Solve a puzzle

Find the hidden word.

👯 Play in pairs

One child encrypts. One child decrypts.

🔍 Notice patterns

Look for the same rule again and again.

8. 🎡 What does the Cipher Wheel show?

The paper wheel in the activity makes the same rule visible. One alphabet stays in place. The other alphabet moves.

OriginalABCDE
Key +2CDEFG

Children can turn the wheel, match letters, and see the pattern instead of only reading about it.

9. 🧠 What Computational Thinking are we using?

👣 Algorithmic Thinking

Follow the steps.

Choose a key → move letters → write the new message.

🧩 Decomposition

Break the job into small parts.

C→E, O→Q, D→F, E→G.

🔍 Pattern Recognition

Notice what repeats.

Every letter moves by the same number.

🔁 Generalisation

Use the same rule again.

The key can change, but the basic rule stays the same.

✅ Evaluation

Check if it worked.

Can the receiver decode the secret message correctly?

10. 🌟 What should the child remember?

🔐 Hide→🔑 Use a key→👣 Follow steps→🔍 Find patterns→🔓 Reveal
“I can make a rule, follow the rule step by step, notice a pattern, and check my answer.”
