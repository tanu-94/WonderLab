Chapter 1 • What’s in a Name?

🔐 Caesar Cipher — understand it before you try it

Based on the Chapter 1 activity, pages 9–13

🌟 What are we learning?

This activity introduces a simple way to hide a message by changing its letters according to one clear rule.

You will learn five simple ideas: secret messages, ciphers, encryption, decryption, and keys. You will also practise following steps and spotting patterns.

🕵️ Why do people use secret messages?

Some information should not be understood by everyone. Passwords, payment details and private messages need protection.

Modern computers use much stronger security methods. The Caesar Cipher is a simple classroom model that helps us understand the basic idea of hiding information.

🔤 What is a cipher?

A cipher is a rule for changing a message so its original meaning is hidden.

The person receiving the message needs the correct key — the information that tells them how the letters were changed.

👑 What is the Caesar Cipher?

The Caesar Cipher is a simple cipher in which every letter is shifted by the same number of places in the alphabet.

🔑Choose a keyThe key is the number of places to move.
🔤Move the lettersEvery letter follows the same rule.
🔒Hide the messageThe changed letters make the coded message.
🔓Use key to decodeMove back using the same key.

🔑 Example: What does “Key +2” mean?

It means every letter moves 2 places forward in the alphabet.

A → CB → DC → ED → F…Y → AZ → B
The alphabet wraps around. After Z, we come back to A.

🔄 How does it work?

1
Choose a wordExample: NANI
2
Choose a keyExample: +2
3
Shift each letterN→P, A→C, N→P, I→K
4
Write the codeNANI → PCPK

🔓 How do we decode?

To decode PCPK with key +2, move each letter back by 2:

P → NC → AP → NK → I
PCPK → NANI
Encode = hide the message. Decode = reveal the message.

🎡 Why use a cipher wheel?

The activity uses two alphabet circles. The smaller circle can turn over the bigger circle.

Align the letters, choose the key, and then use the matching letters to encode or decode one letter at a time.

👯 How can two friends play?

Friend A: choose a short message, choose a key, encode the message, and give the coded message plus the key to Friend B.

Friend B: use the same key, decode each letter, and discover the original message.

Good messages for children can be a name, a school name, or a food item from their lunchbox.

🧠 What Computational Thinking is happening here?

The activity is not only about secret codes. It gives children a simple problem and asks them to follow a rule, break the job into parts and notice what repeats.

👣 Algorithmic Thinking

Follow the steps in order: choose a key → shift letters → write the result.

🧩 Decomposition

Break the message into individual letters and solve one small part at a time.

🔍 Pattern Recognition

Notice that every letter moves by the same number of places.

🔁 Generalisation

Realise that the same rule works for different words and different keys.

🚦 Is Caesar Cipher used for bank or UPI security?

No. It is a simple learning model, not modern security.

The activity explains that there are only a small number of possible shifts, so this method is not strong enough for protecting real financial information. Modern systems use much more sophisticated security methods.
