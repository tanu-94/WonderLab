What is CT & AI in Class 3?

A simple, clear guide for teachers and parents: what these terms mean, why they matter, and how children use them in everyday life.

THE HUMAN HABIT

1. Computational Thinking (CT)

What it is: A step-by-step problem-solving method. Children learn to break a big problem into smaller parts, spot patterns, focus on what matters, and create clear steps.

Where do children use CT?
  • In School: Solving maths problems, organising information, and following multi-step tasks.
  • At Home: Packing a school bag, following a recipe, or giving directions.
  • In Technology: CT provides the logical foundation used before writing software.
THE MACHINE APPLICATION

2. Artificial Intelligence (AI)

What it is: Technology that enables computers and machines to perform tasks that usually require human-like abilities, such as recognising patterns, making predictions, solving problems, and making choices.

Where do children see AI in daily life?
  • Voice Recognition: A device recognising what someone says.
  • Maps: Suggesting routes based on information and patterns.
  • Everyday Technology: Helping computers recognise images, language, patterns, or recommendations.

💡 Why start with thinking before coding?

For Class 3, the goal is not to teach programming syntax first. Children first build the thinking habits behind technology — logical reasoning, problem solving, pattern recognition, sequencing and clear instructions — through stories, games, paper activities and discussion.

Get Ready for the Caesar Cipher Activity

A little preparation makes the activity smooth, playful, and easy for every Class 3 learner.

The goal is not to teach coding. The goal is to let children make a rule, follow it, notice a pattern, and explain their thinking.

📋 Before the class

  • 👥 Make partners: Plan pairs before the activity begins.
  • 📄 Ready the worksheet: Print the Caesar Cipher worksheet for the children.
  • ✂️ Keep child-friendly scissors ready: Children will cut out the cipher wheel pieces.
  • 📎 Keep the simple joining material needed to assemble the wheel ready.
  • 🧑‍🏫 Keep one completed/demo cipher wheel ready so you can model the first example.

🎒 Materials checklist

☐ Printed worksheet
☐ Child-friendly scissors
☐ Pencil / crayons
☐ Joining fastener / split pin
☐ One teacher demo wheel
☐ Partner seating

✅ Do's

  • Let children try, discuss, and discover.
  • Ask: “How did you figure that out?”
  • Let partners explain the rule to each other.
  • Encourage children to use the physical cipher wheel.
  • Praise reasoning and explanation, not just the final answer.

🚫 Don'ts

  • Don't give the answer immediately.
  • Don't turn this into a coding lesson.
  • Don't ask children to type or write code.
  • Don't make children work alone when the activity is designed for partners.
  • Don't worry about perfect cutting — the thinking is the important part.

⏱️ Suggested classroom flow

1. Prepare & introduce5 min
2. Make / use the wheel10–15 min
3. Partner challenge10 min
4. Discuss the thinking5 min

1. 🌟 What is the Caesar Cipher?

It is a simple way to hide a message.

We move every letter by the same number of places in the alphabet.

ABCDE
⬇️ Shift +2 ⬇️
CDEFG

The number of places we move is called the key.

2. 💡 What does it mean?

🔐 Encrypt = hide

Change the message using the rule.

CODE → EQFG
🔓 Decrypt = reveal

Use the key to bring the message back.

EQFG → CODE
🔑 Key = 2

Every letter moves 2 places forward when we hide the message.

C → EO → QD → FE → G

3. 🕵️ Why do we use this idea?

Sometimes information should not be understood by everyone.

🔑PasswordKeep private
💳Payment informationKeep safe
📱Private messageKeep private
Important: The Caesar Cipher is a classroom model. Modern computers use much stronger security methods to protect real information.

4. 🌍 Where is the idea used?

The idea of protecting information is used when people use passwords, make payments, shop online, or send private information.

🔑Password
💳Online payment
🛒Online shopping
📱Private communication

Remember: Caesar Cipher itself is not the security system used for today's banking or UPI. It is a simple model for learning how a rule can hide information.

5. 👥 Who can use it?

Anyone who knows the rule can use it. One person hides the message. The other person uses the same key to reveal it.

8. 🎡 What does the Cipher Wheel show?

The paper wheel in the activity makes the same rule visible. One alphabet stays in place. The other alphabet moves.

Children can turn the wheel, match letters, and see the pattern instead of only reading about it.

9. 🧠 What Computational Thinking are we using?

👣 Algorithmic Thinking

Follow the steps.

Choose a key → move letters → write the new message.

🧩 Decomposition

Break the job into small parts.

C→E, O→Q, D→F, E→G.

🔍 Pattern Recognition

Notice what repeats.

Every letter moves by the same number.

🔁 Generalisation

Use the same rule again.

The key can change, but the basic rule stays the same.

✅ Evaluation

Check if it worked.

Can the receiver decode the secret message correctly?

10. 🌟 What should the child remember?

🔐 Hide→🔑 Use a key→👣 Follow steps→🔍 Find patterns→🔓 Reveal
“I can make a rule, follow the rule step by step, notice a pattern, and check my answer.”

🧩 Pages 12–14 • Solve the Questions

12. ✏️ Let’s solve it step by step

These are the Chapter 1 Caesar Cipher questions from pages 12–14. Children can try first, then open the explanation with the teacher or partner.

Page 12 • Question 1

Complete the table by shifting the alphabet.

OriginalABCDEFGHIJKLMNOPQRSTUVWXYZ
Shift 1BCDEFGHIJKLMNOPQRSTUVWXYZA
Shift 2CDEFGHIJKLMNOPQRSTUVWXYZAB
Shift 20UVWXYZABCDEFGHIJKLMNOPQRST
💡 How to solve: Move every letter forward by the same number. When you reach Z, continue from A.
Page 12 • Question 2

If “CAESAR CIPHER” is encoded with a shift of 3 places, which is correct?

A. ECGUCT EKRJGTB. FDHVDU FLSKHU ✓C. GEIWEV GMTLIVD. DBFTBS DJQIFS
Answer: B — FDHVDU FLSKHU
💡 Solution: Shift each letter 3 places: C→F, A→D, E→H, S→V, A→D, R→U. So CAESAR → FDHVDU. Similarly, CIPHER → FLSKHU.
Page 13 • Question 3

“THIS MESSAGE IS HIDDEN” becomes “ESTD XPDDLRP TD STOOPY”. By how many positions was the alphabet shifted?

A. 5B. 11 ✓C. 17D. 7
Answer: B — 11 positions
💡 Solution: Compare one original letter with its encoded letter. T→E means moving 11 places around the alphabet. Check again: H→S, I→T, S→D. The same shift works each time, so the key is 11.
Page 14 • Question 4

How many possible meaningful ways are there to shift the alphabet in a Caesar Cipher?

A. 26B. 52C. 25 ✓D. 50
Answer: C — 25 meaningful shifts
💡 Solution: The alphabet has 26 letters, but a shift of 26 brings every letter back to itself. That changes nothing. Therefore, shifts 1 through 25 are the meaningful choices.
🧠 CT Thinking: These questions practise Algorithmic Thinking, Decomposition, Pattern Recognition, Generalisation, and Evaluation. The goal is not only to select an answer, but to explain the rule used to get there.
